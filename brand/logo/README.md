# weathership logo

Three shapes — mark, wordmark, lockup — each with a small set of
variants. Every shape has an SVG master; the rest of the files are
mono recolorings or PNG renders generated from the master.

## Variants

### Mark (icon-only, square)

| File | Description |
|------|-------------|
| `mark/mark.svg` | Master. Two-tone — the "sail" strokes are `--ws-sun` against the `--ws-sea` core. |
| `mark/mark-mono-black.svg` | Single-color `--ws-ink` rendering for print and single-color contexts on light. |
| `mark/mark-mono-white.svg` | Single-color `--ws-paper` rendering for use on `--ws-ink` and photographic backgrounds. |
| `mark/mark-{16,32,48,192,512}.png` | PNG renders at standard pixel sizes; generated by `render-pngs.sh`. |

### Wordmark (text only)

| File | Description |
|------|-------------|
| `wordmark/wordmark.svg` | Master. "weathership" in Inter 600 with custom kerning. |
| `wordmark/wordmark-mono-black.svg` | Inked variant. |
| `wordmark/wordmark-mono-white.svg` | Paper variant for dark surfaces. |

### Lockup (mark + wordmark)

| File | Description |
|------|-------------|
| `lockup/lockup-horizontal.svg` | Mark left, wordmark right, baselines aligned. Default. |
| `lockup/lockup-stacked.svg` | Mark above, wordmark centered below. For square placements. |
| `lockup/lockup-mono-black.svg` | Single-color horizontal lockup. |
| `lockup/lockup-mono-white.svg` | Single-color horizontal lockup for dark surfaces. |

## Concept

The mark reads as **W** at first glance and as a **horizon line crossed
by two ascending strokes** at second glance — a horizon (waterline) and
two sails catching wind. Built on a 24×24 grid for clean rendering at
16/32/48 px.

The two-tone variant uses `--ws-sun` for the sails (motion, light, the
read-conditions part of the name) and `--ws-sea` for the hull line and
horizon (durability, the platform part).

## Authoring

All paths in the master SVGs are integer-aligned to the 24×24 grid
(or, for the wordmark, to whole-pixel x-positions at 64 px cap height).
Don't introduce sub-pixel coordinates — they degrade rendering at
small sizes. If a curve needs to land between integers, redraw it.

## Regenerating renders

```sh
just brand-render
```

Walks every SVG master under `brand/{logo,favicon,social,typography}/`,
rasterizes via `rsvg-convert` at the documented sizes, and strips
metadata via `optipng`.

## Safe area

See [`safe-area.md`](./safe-area.md). The minimum clear space is one
cap-height of the wordmark on every side; the minimum on-screen size is
16 px (mark) / 80 px (wordmark) / 120 px (horizontal lockup).
