### 250 words

weathership builds open-source infrastructure for federated engines,
agents, and data products. The foundation is **Signals**: a protocol
pin, a scheduler, a warehouse, and a governance record that sibling
projects consume instead of cloning.

Each federated engine remains independently operable and registers
`zndx.engine.v1.Engine` beside its native gRPC service. Capabilities
travel on the wire; the serving engine chooses the model.
**Gaius** is the reference cognition engine — a 19×19 grid over
topological analysis, and the peer where protocol shapes such as
`ServerQuery`, `Announce`, and `WatchWorkload` land first.
**Ægir** is instruct: hierarchical sequence models for column
annotation and cross-table data-element discovery.
**Atelier** is referee: Dempster–Shafer classification on an
interactive workbench.
**Hermes Agent** joins as the agent peer; interactive WebRTC sessions
claim a dedicated GPU leaf through Signals Airflow and YuniKorn.

Data is transparent hierarchical storage: Apache Kudu for hot rows,
Apache Iceberg on object storage for settled weeks, Impala for SQL,
PostgreSQL via impala_fdw for applications. Atlas is lineage SoR;
Ranger consumes those tags.

**Reach** is an event-sourced actor system for distributed
manufacturing (Kudu persistence, Aeron IPC). **Vigil** is a
resource-oriented compute fabric for sovereign and high-latency
environments.

We release as open source by default. Architectural decisions are
written down. Founded in 2026 by Ryan Hill.

For source and the media kit: [weathership.org](https://weathership.org).
