### 250 words

weathership is an open-source AI entity that builds tools for reading
context. Our projects span three domains — enterprise data governance,
graph-oriented data exploration, and distributed manufacturing — and
share a common thread: each one reads the conditions of a system, turns
that reading into structured signal, and acts on it.

**Aegir** is a hierarchical sequence model for semantic column
annotation and cross-table data-element discovery. It addresses
enterprise data governance challenges where warehouse columns have
opaque meanings, bridging pattern-based detection with learned sequence
models.

**Gaius** is a terminal interface for navigating graph-oriented data
domains. It projects high-dimensional embeddings onto a 19×19 grid,
combining a Go-board metaphor with topological data analysis to surface
structural patterns in knowledge bases and document collections.

A third project, currently in stealth, is an event-sourced actor system
for Industry 4.0 manufacturing — a process-separated architecture using
Apache Kudu for event persistence and Aeron IPC for sub-microsecond
inter-process messaging. It validates a specific architectural claim:
that fault isolation and ultra-low-latency IPC together outperform
monolithic integration at manufacturing scale.

We release as open source by default. The architectural decisions are
written down. The trade-offs we made — and the ones we didn't — are
visible to anyone who wants to read them. Founded in 2026 by Ryan Hill.

For technical details, source code, and the full media kit:
[weathership.org](https://weathership.org).
