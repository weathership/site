# weathership brand package

This directory is the canonical source-of-truth for the weathership brand:
the writing that defines our voice, the tokens that define our look, and
the SVG masters that produce every logo, favicon, and social card we ship.

The website at `web/` reads from this directory. The public-facing
`/media-kit/` pages are a window onto these files. Edit here; the rest of
the site reflects the change.

## What's here

| Path | Purpose |
|------|---------|
| `identity.md` | Who weathership is. Mission, values, tagline. |
| `voice-tone.md` | How we write. Tense, person, what we sound like and don't. |
| `usage-guidelines.md` | How the marks may and may not be used. |
| `press-kit.md` | 50/100/250-word boilerplate, founder bios, press contact. |
| `colors/palette.md` | Token table with hex/RGB/HSL/CMYK and contrast pairs. |
| `colors/tokens.css` | CSS custom properties consumed by the site. |
| `typography/system.md` | Type stack rationale and fallbacks. |
| `typography/specimens.svg` | Hand-rendered type ramp. |
| `logo/` | Mark, wordmark, and lockup SVG masters + PNG renders. |
| `favicon/` | Favicon vector + raster sizes. |
| `social/` | OG image, Twitter banner, profile avatar. |
| `render-pngs.sh` | Regenerates PNG renders from SVG masters. |

## Editing rules

1. **Edit the SVG master, not the PNG.** PNGs are regenerated by
   `./render-pngs.sh` (or `just brand-render` from the repo root).
2. **Color values live in `colors/tokens.css`.** Don't hard-code hex in
   SVGs unless the variant is explicitly mono-black or mono-white.
3. **Keep paths aligned to the 24×24 mark grid.** Crisp rendering at 16,
   32, and 48 px depends on integer-aligned coordinates.
4. **No raster placeholders.** Every published asset is a real, finished
   piece.
